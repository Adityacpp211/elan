## 👤 **Member 2: Backend Architecture** (~12 min)
### Topic: Node.js Server & API Design

**Key Points to Cover:**

### 1. Technology Stack (3 min)
- **Node.js** runtime with **Express.js** framework
- RESTful API architecture
- **JWT** (JSON Web Token) for authentication
- **bcryptjs** for password hashing (10 rounds)
- **Axios** for HTTP requests

### 2. API Endpoints (6 min)

#### Authentication Routes
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/register` | Register new user |
| `POST` | `/api/auth/login` | Login user |
| `POST` | `/api/auth/location` | Update user location |

#### Hospital Routes
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/hospitals/nearby` | Find nearby hospitals by GPS |

#### Payment Routes
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/payments/create-order` | Create Razorpay order |
| `POST` | `/api/payments/verify` | Verify payment |

#### Alert Routes
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/alerts/send` | Send emergency alert |
| `GET` | `/api/alerts/history` | Get alert history |

### 3. Security Features (3 min)
- Bearer token authentication on protected routes
- Password encryption with bcrypt
- CORS enabled for cross-origin requests
- Token expiry management

## 👤 **Member 4: Emergency System & Notifications** (~12 min)
### Topic: Core Emergency Alert Flow + Firebase FCM

**Key Points to Cover:**

### 1. Tiered Alert System (4 min)

| Tier | Cost | Hospitals Notified |
|------|------|-------------------|
| **Tier 1** | ₹1 | 1 nearest hospital |
| **Tier 2** | ₹2 | 3 nearest hospitals |
| **Tier 3** | ₹3 | All nearby (up to 10) |

### 2. Emergency Alert Flow (5 min)

```
Step 1: User Opens Emergency Screen
    ↓
Step 2: Select Alert Tier (1, 2, or 3)
    ↓
Step 3: Confirm GPS Location (auto-detected)
    ↓
Step 4: Add Custom Message (optional)
    ↓
Step 5: Check Wallet Balance
    ↓
Step 6: If insufficient → Razorpay Payment
    ↓
Step 7: Create Alert Record in Database
    ↓
Step 8: Find Nearby Hospitals (by proximity)
    ↓
Step 9: Send Email Alerts to Hospitals
    ↓
Step 10: Send FCM Push Notifications
    ↓
Step 11: Display Confirmation to User
    ↓
Step 12: Update Alert History
```

### 3. Firebase Cloud Messaging (FCM) (3 min)
- **Push notifications** sent to hospital devices
- Multi-channel notification system:
  - Email alerts
  - FCM push notifications
- Real-time alert delivery (< 30 seconds)
- Firebase Admin SDK integration
